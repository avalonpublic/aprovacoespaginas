# STACK — RENX Design System

- **Lucide Icons** — biblioteca de ícones open-source usada via CDN (unpkg) para todos os ícones da interface
- **Geologica** — fonte Google Fonts usada como tipografia de display e body (substitui Seeker para web)
- **Space Mono** — fonte Google Fonts usada para labels mono, identificadores técnicos e eyebrows
- **CSS Custom Properties** — sistema de design tokens nativo (cores, espaçamento, tipografia, gradientes)
- **IntersectionObserver API** — dispara animações de reveal ao scroll (scroll-reveal.js, slider-pagination.js)
- **CSS Animations / @keyframes** — engine de animação nativa (animations.css): marquee, spin, flicker, cardStack, kenBurns, shimmer, beam
- **CSS backdrop-filter** — glassmorphism e blur effects (effects.css, components.css)
- **CSS mask-composite / -webkit-mask** — border gradient trick extraído do instagram-slides reference
- **CSS conic-gradient** — border beam rotativo nos botões (components.css)
- **CSS scroll-snap** — horizontal slider com snap point (layout.css, slider-pagination.js)
- **Vanilla JavaScript** — toda a lógica de interação (scroll-reveal.js, carousel.js, interactions.js, slider-pagination.js)
- **CSS Grid / Flexbox** — sistema de layout principal sem dependência de framework externo
- **Google Fonts API** — entrega das fontes Geologica e Space Mono via CDN
